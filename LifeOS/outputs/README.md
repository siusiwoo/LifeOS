# LifeOS 웹 미리보기

## Python으로 웹에서 열기

Windows에서는 같은 폴더의 `start-lifeos.bat`을 더블클릭하면 Python 서버가 실행되고 기본 브라우저가 열립니다. Python이 설치되어 있어야 합니다. 서버 창을 닫으면 접속이 종료됩니다.

직접 실행하려면 `python server.py`를 사용하세요. 기본 주소는 `http://127.0.0.1:8765/`이며 이 컴퓨터에서만 접속할 수 있습니다. 포트를 바꾸려면 `python server.py --port 8766`으로 실행합니다. `server.py`와 `lifeos.html`을 같은 폴더에 보관하세요.

HTML 파일을 직접 열었을 때와 웹 주소로 접속했을 때의 브라우저 저장 공간은 서로 다릅니다. 기존 로컬 파일의 기록이 자동으로 옮겨지지는 않습니다.

`lifeos.html`을 Chrome, Edge, Safari 등 최신 브라우저에서 열면 됩니다. 설치, 서버, 인터넷 연결이 필요 없는 단일 HTML 파일입니다.

## 사용 방법

- 상단의 날짜 버튼 또는 달력 입력으로 날짜를 선택합니다. 모든 영역은 같은 선택 날짜를 사용합니다.
- 좌우 화살표는 1주 단위로 이동하며, `오늘로 이동`은 현재 날짜로 돌아갑니다.
- 최초 실행은 빈 상태로 시작합니다. 날짜별로 기록을 추가하면 해당 날짜에만 표시됩니다.
- Dashboard는 전체 요약, Work는 업무, Growth는 학습·회고, Money는 자산·부업 내역을 보여 줍니다.
- `기록 추가`, 각 항목의 `수정`, 수정창의 `삭제`를 사용할 수 있습니다. 업무의 체크 버튼으로 완료 상태를 변경합니다.
- 기본 학습 카테고리는 `코딩`, `회로 기초`입니다.
- 자산은 선택 날짜에 직접 기록한 잔액의 합계입니다. 이전 날짜의 잔액을 자동으로 가져오지 않습니다. 부업 수익은 해당 날짜의 기록만 합산합니다.

## 저장 방식

변경사항은 해당 브라우저의 localStorage에 저장합니다. 같은 파일을 같은 브라우저에서 다시 열면 지원 환경에서 유지됩니다. 파일 이동, 브라우저 변경, 비공개 모드, 브라우저 데이터 삭제 시 유지되지 않을 수 있습니다. 저장을 사용할 수 없으면 화면 상단에 안내합니다. 계정 동기화와 실제 금융 연동은 없습니다.

## 확장 구조

HTML 안의 CSS와 JavaScript는 외부 파일 없이 포함되어 있습니다. JavaScript는 다음 경계를 기준으로 구성했습니다.

- **모델:** `version`, `categories`, `days[YYYY-MM-DD]`. 날짜별로 `work`, `growth`, `assets`, `income`, `reflection`을 저장합니다.
- **Repository:** 데이터 조회·저장·수정·삭제를 담당합니다. 서버 연동 시 이 계층을 비동기 API 호출로 바꾸고 화면의 저장/로딩 처리를 추가하면 됩니다.
- **상태:** `state.date`, `state.view`, `state.editing`으로 선택 날짜·메뉴·편집 대상을 관리합니다.
- **화면:** `render`, `renderDate`, 각 영역의 카드 렌더링 함수로 분리되어 있습니다.
- **카테고리:** 이름 대신 `categoryId`를 기록에 저장합니다. 카테고리 CRUD 화면과 Repository 메서드를 추가할 수 있는 구조이며, 이번 버전의 카테고리 관리 UI는 포함하지 않았습니다. 삭제 시 연결 기록의 처리 정책을 추가해야 합니다.

금액은 원 단위 정수, 학습 시간은 분 단위 정수, 날짜는 현지 날짜 문자열을 사용합니다. 업무·학습·자산·부업 기록에는 고유 ID가 있습니다. 회고는 날짜당 하나를 저장합니다. 사용자 입력은 HTML 이스케이프 후 표시합니다.
